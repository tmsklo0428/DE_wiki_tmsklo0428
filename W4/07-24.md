## 🔄 KPT

### Problem
- 문제를 명확히 정의하지 않은 채, 가진 데이터로 해결 가능한 문제를 역으로 정의하려고 했다.
  → 문제 정의와 데이터를 활용한 문제 해결은 서로 다른 단계이며, 이 둘의 고리를 끊고 문제 정의를 먼저 검증한 뒤에 해결 방법을 고민해야겠다.
- "누구의 어떤 문제를 해결할 것인가"를 구체적으로 좁히지 않고 넓은 범위의 니즈를 다루려고 했다.
  → 아주 좁고 구체적인 고객 니즈에서 시작해 점차 확장하는 방식으로 문제를 설정해야겠다.
- 보고서에 문제의 배경과 과정을 상세히 설명하려다 보니 내용이 vlog처럼 장황해졌다.
  → 보고서는 기록이 아니라 의사결정을 위한 문서이므로, 문제와 결론 중심으로 핵심만 두괄식으로 적어야겠다.
